# SWYNEX Final Data Analytics Project

## Project Overview

This project focuses on data cleaning, exploratory data analysis, and dashboard creation to identify useful trends and insights from the given dataset.

## Dataset

The project uses the provided dataset containing transaction-related information for analysis.

## Data Cleaning

The dataset was cleaned and prepared before analysis. The cleaning process included checking the data, handling inconsistencies, and preparing the data for further analysis.

## Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed using Excel to understand the data and identify important patterns and trends.

## Dashboard

An interactive dashboard was created using Power BI to present the key findings through visualizations and make the analysis easier to understand.

## Key Insights

- Identified important patterns and trends in the dataset.
- Analyzed transaction-related information.
- Used visualizations to compare categories and performance.
- Presented the findings through an interactive Power BI dashboard.

## Tools Used

- Microsoft Excel
- Power BI
- CSV Dataset
